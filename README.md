# GEPA Merge — Submission Package

Code and result artifacts for **"When Does GEPA Merge Help? A Mechanism-Level Diagnostic"**.

The bundle contains three things:

1. **Code** — the GEPA fork used for every experiment, plus launch and analysis scripts.
2. **Results** — every run directory referenced in the paper (sweep, variance audit, reflection-cap counterfactual, behavioral probe), organized by paper section.
3. **Analysis outputs** — text/CSV artifacts produced by the analysis scripts on these results, matching the numbers in §4–§6 of the paper.

No figures are generated by this bundle. The numbers behind every figure live in `results/analysis_output/`.

### `results/` — organized by paper section

Each run dir contains `best_candidate.json`, `gepa_state.bin`, `merge_quality.jsonl`, and `test_eval.json` (300-example held-out test score).

| Folder | Paper ref |
|---|---|
| `sec4_configuration_sweep_seed0/<model>/<task>/<cell>/` — 3 operators × 3 timings + NoMerge, single seed | §4.2, Fig 3 |
| `sec4_variance_audit_seed{1,2}/<model>/<task>/<cell>/` — multi-seed NoMerge + selected merge re-runs | §4.4, Tab 3 |
| `sec5_reflection_cap_counterfactual/` — Qwen runs with reflection LM capped at 2000 tokens | §5.2 |
| `sec6_behavioral_probe/<model>/<task>/<cell>/` — locked four-layer probe (adaptive\_s{1,2} + probe-wave companions); CSV mirrors in `test_eval_csvs/` | §6.2, Fig 4, Tab 7 |
| `sec6_adaptive_seed0_{gpt,qwen}/` — s=0 adaptive runs (s=0 column of Tab 7) | §6.2 |
| `replay/` — adaptive-replay sensitivity sweep over thresholds | §6 |
| `test_score_aggregates/` — long-form aggregate CSVs (input to timing analysis) | §4 |
| `analysis_output/` — **outputs of the analysis scripts** (see below) | §4 – §6 |

## Replication

> All shell scripts read API keys from environment variables — keys are never stored in the repo. `experiments/benchmarks/run_dspy.py` routes by provider prefix on `--model` (`openai/`, `qwen/`, etc.); set whichever of `OPENAI_API_KEY`, `OPENROUTER_API_KEY`, `PRIME_API_KEY` matches your provider.

### 0. One-shot setup (per machine)

```bash
cd gepa_submit
bash experiments/setup.sh                       # uv venv, deps, vendored DSPy programs
PYTHONPATH=src .venv/bin/python experiments/warmup_wiki_corpus.py   # ~608MB, ~15 min
```

### 1. Configuration sweep (§4.2, Figure 3)

```bash
OPENAI_API_KEY=<key> MODEL=openai/gpt-4.1-mini bash experiments/run_phase_a.sh
OPENAI_API_KEY=<key> MODEL=qwen/qwen3-8b       bash experiments/run_phase_a.sh
```

Env knobs (see the head of `run_phase_a.sh`):

| Var | Default | Meaning |
|---|---|---|
| `TASK_LIST` | `ifbench hotpotqa hover` | space-separated benchmarks |
| `MERGE_ALGO_ONLY` | all three | subset of `original combine_all summarize_before` |
| `START_ONLY` | all three | subset of `immediate score_plateau budget_proportional` |
| `SEED_ONLY` | `0 1 2` | seeds; for §4.4 variance audit run 0, 1, 2 |
| `INCLUDE_NOMERGE` | `yes` | pair each seed with a NoMerge baseline |
| `RUNS_ROOT` | `runs/sweep` | output directory |

Single-cell smoke check (~10 min, ~$1):

```bash
OPENAI_API_KEY=<key> MODEL=openai/gpt-4.1-mini \
    TASK_LIST=hotpotqa MERGE_ALGO_ONLY=original START_ONLY=immediate \
    SEED_ONLY=0 INCLUDE_NOMERGE=no \
    bash experiments/run_phase_a.sh
```

### 2. Behavioral probe (§6)

```bash
OPENAI_API_KEY=<key> MODEL=openai/gpt-4.1-mini bash experiments/run_adaptive_probe.sh
OPENAI_API_KEY=<key> MODEL=qwen/qwen3-8b       bash experiments/run_adaptive_probe.sh
```

Same env knobs as the sweep. The script enables `--use_merge --adaptive_merge_enabled` (the locked four-layer policy from Appendix C; all thresholds are constants in `src/gepa/strategies/adaptive_merge.py`).

### 3. Held-out test evaluation

```bash
OPENAI_API_KEY=<key> RUNS_ROOT=runs/sweep bash experiments/run_test_eval.sh
```

Walks `RUNS_ROOT`, finds every directory with `best_candidate.json`, reconstructs the optimized program, evaluates on the held-out 300-example test set, writes `test_eval.json` next to each `best_candidate.json`, and aggregates to `RUNS_ROOT/test_eval_summary.csv`.

### Writing your own launch script

Every run boils down to one invocation:

```bash
PYTHONPATH=src .venv/bin/python -m experiments.benchmarks.run_dspy \
    --task <task>                       # ifbench|hotpotqa|hover|musique|twowikimultihopqa
    --model <model>                     # e.g. openai/gpt-4.1-mini, qwen/qwen3-8b
    --reflection_lm <model>             # paper default: same as --model
    --max_metric_calls <N>              # paper budgets: 6871 (hotpotqa, musique, 2wiki),
                                        #                7051 (hover), 3593 (ifbench)
    --run_dir <out_dir>
    --seed <0|1|2>
    [--use_merge --merge_algorithm <original|combine_all|summarize_before>
                 --merge_start <immediate|score_plateau|budget_proportional>]
    [--adaptive_merge_enabled]          # turn on the §6 behavioral probe
    [--merge_quality]                   # log merge_quality.jsonl
```

All CLI flags are documented inline in [experiments/benchmarks/run_dspy.py](experiments/benchmarks/run_dspy.py) (grep for `parser.add_argument`).

## Analysis

Every command below runs against the artifacts under `results/` and writes its output into `results/analysis_output/`. The pre-computed outputs are already there; the commands are reproducible end-to-end.

### Aggregate test scores across seeds — Figure 4 / Table 7

```bash
.venv/bin/python analysis/evolution/variance_summary.py > results/analysis_output/variance_summary.txt
```

### Reflect-vs-merge per-step Δval + val/test correlation — Table 4 / Table 5

```bash
.venv/bin/python analysis/evolution/stage0_build_gpt.py        # rebuilds analysis/evolution/candidates.csv
.venv/bin/python analysis/evolution/compute_gpt_stats.py > results/analysis_output/compute_gpt_stats.txt
```

### Per-cell merge-timing summary — §4 catastrophe table

```bash
.venv/bin/python experiments/analysis/timing_summary.py \
    --runs_roots results/sec4_configuration_sweep_seed0/gpt-4.1-mini \
                 results/sec4_configuration_sweep_seed0/qwen3-8b \
    --scores_csv results/test_score_aggregates/sec4_seed0_test_scores.csv \
    --out results/analysis_output/cell_timing.csv
```

### Prompt-feature acceptance classifier — Table in §5.1

```bash
.venv/bin/python experiments/analysis/logistic_acc_vs_rej.py \
    --accepted_csv results/analysis_output/forensics_v3/accepted_deterministic_metrics.csv \
    --rejected_csv results/analysis_output/forensics_v3/rejected_deterministic_metrics.csv \
    --out_csv     results/analysis_output/logistic_acc_vs_rej.csv
```

The 5-model AUC table prints to stdout (and is captured into `logistic_acc_vs_rej.csv`).

### Reflect-vs-merge Δval distribution (Mann-Whitney supplement)

```bash
.venv/bin/python analysis/evolution/stage2_compare.py > results/analysis_output/stage2_compare.txt
```
